# MERIDIAN — Specialty Coffee

A sober, minimal static website for a specialty coffee roaster, inspired by the
clean, Helvetica-driven aesthetic of studiogogo.de.

## Design

- **Typography:** Helvetica / Arial system stack, no web fonts.
- **Palette:** white background, near-black ink, muted grey, hairline borders.
- **Layout:** generous whitespace, simple top navigation, product grid, minimal footer.

## Structure

| File | Page |
| --- | --- |
| `index.html` | Home — hero, intro, featured coffee, philosophy |
| `shop.html` | Product grid |
| `about.html` | Story |
| `contact.html` | Contact details |
| `styles.css` | Shared styling |

## Run

Open `index.html` in a browser, or serve the folder:

```sh
python3 -m http.server
```
